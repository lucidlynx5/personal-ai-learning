# FIELDNOTES / 景观竞赛观察

黑白主色、绿色强调的双语景观竞赛索引，为职业景观设计师与年轻团队整理国内外机会。

**网站：** https://lucidlynx5.github.io/personal-ai-learning/

## 初版功能

- 中文 / English 界面及双语竞赛摘要、要求与备注。
- 项目征集 / 概念竞赛 / 设计奖项分类。
- 地区、资格、费用、状态、官方核对程度筛选；搜索与排序。
- 单条竞赛和筛选结果的分享链接（查询参数）；浏览器本地收藏。
- 报名与交稿时间分开处理；已截止项目自动归档。
- 每条显示来源和核查时间，无法确认的费用、资格、截止时刻明确保留。
- 数据超过72小时未成功更新会提示；网络加载失败有重试入口。

## 自动更新

ChatGPT 自动任务每两天执行网络检索、原始来源复核，并通过 GitHub 更新数据；不依赖浏览器打开。
首个计划运行：2026-11-13 08:00，Asia/Shanghai，灵活调度。创建时尚未完成首次无人值守运行。
数据的 `automation` 字段记录计划与状态；`updatedAt` 表示成功数据快照时间，而不是当前时间。
覆盖、失败与数据协议见 [docs/UPDATE_PROTOCOL.md](docs/UPDATE_PROTOCOL.md)。

初始10条真实记录（9条当前进行中、1条归档），16个来源渠道目录。目录包含待首轮核查来源，不代表所有渠道均已接入API。初始内容是一个有限样本，并非完整竞赛数据库。

## 技术与维护

原生 HTML / CSS / JavaScript，无依赖、无构建步骤、无API密钥。`main` 根目录通过既有 GitHub Pages 发布。
数据入口：`data/competitions.json`；纯逻辑：`core.mjs`；交互与翻译：`app.js`。
本地使用任意静态 HTTP 服务预览（ES modules 不能直接用file://）。

```sh
node scripts/validate-data.mjs
node scripts/check.mjs
node --check app.js
```

验证限制：本轮缺少当前托管预览要求的 `cua_repl.js` 控制工具，没有进行浏览器视觉和交互验收。完成数据、日期边界、组合筛选、静态资产、JavaScript语法及发布检查。应在下一轮有浏览器工具时补做375/768/1440px中英文视觉与键盘操作验收。

收藏仅存当前浏览器，不会跨电脑同步，也不代表团队共享收藏。分享链接打开的是公开竞赛内容和筛选，不包含队友的私有数据。
